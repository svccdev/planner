# Настройка push-уведомлений планера

Ниже — порядок действий с нуля. Эти шаги создают отдельный Cloudflare Worker и небольшую базу D1. Сам сайт по-прежнему размещается на GitHub Pages.

## Что будет храниться

- В Cloudflare: push-подписка телефона, часовой пояс, дата и признак незакрытых основных квестов, а также случайный ID и время созвона.
- Описание созвона остаётся только в браузере телефона. В уведомлении будет общий текст «Созвон через 10 минут».
- Приватный VAPID-ключ хранится только как секрет Worker в Cloudflare. Не добавляй его в GitHub и не присылай никому.

## Часть 1. Обнови сайт на GitHub Pages

1. На компьютере установи **GitHub Desktop** и войди в свой GitHub.
2. В GitHub Desktop нажми **File → Clone repository**, найди `svccdev/planner` и нажми **Clone**.
3. Распакуй архив с планером. Скопируй его файлы и папку `cloudflare` в папку клона `planner`. Подтверди замену `index.html` и `sw.js`; новые файлы `push-config.js` и `cloudflare` тоже должны попасть в папку.
4. Пока не редактируй `push-config.js` — сначала создай Worker и получи его адрес и публичный ключ.
5. Вернись в GitHub Desktop, напиши короткое описание, например `Добавлены push и созвоны`, нажми **Commit to main**, затем **Push origin**.

## Часть 2. Создай Worker и базу Cloudflare

1. Установи Node.js версии LTS с [официального сайта](https://nodejs.org/). После установки открой новое окно PowerShell.
2. В GitHub Desktop нажми правой кнопкой по репозиторию `planner` → **Show in Explorer**. Открой папку `cloudflare`.
3. В адресной строке Проводника напечатай `powershell` и нажми Enter. Откроется PowerShell уже в нужной папке.
4. Введи по очереди команды:

   ```powershell
   npm install
   npx wrangler login
   ```

   Во время входа браузер откроет Cloudflare. Войди в свой аккаунт и разреши Wrangler доступ к нему.

5. Создай базу:

   ```powershell
   npx wrangler d1 create quest-panel-push
   ```

   Cloudflare покажет `database_id` — длинный идентификатор. Скопируй его.
6. Открой файл `cloudflare/wrangler.toml` в Блокноте. Найди строку `database_id = "REPLACE_WITH_D1_DATABASE_ID"` и замени только текст внутри кавычек на выданный идентификатор. Сохрани файл.
7. В PowerShell примени структуру базы:

   ```powershell
   npx wrangler d1 migrations apply quest-panel-push --remote
   ```

   Если появится вопрос о применении миграции, подтверди его.

## Часть 3. Создай ключи и запусти Worker

1. Сгенерируй пару VAPID-ключей:

   ```powershell
   npx web-push generate-vapid-keys
   ```

   Сохрани отдельно значения `Public Key` и `Private Key`. Не публикуй приватный ключ.
2. Укажи контактный адрес для технической идентификации push-сервера: в `cloudflare/wrangler.toml` замени `YOUR-EMAIL@example.com` в `VAPID_SUBJECT` на свой email, сохрани файл.
3. Добавь ключи как секреты. После каждой команды вставь соответствующее значение и нажми Enter:

   ```powershell
   npx wrangler secret put VAPID_PUBLIC_KEY
   npx wrangler secret put VAPID_PRIVATE_KEY
   ```

   В окно PowerShell вводимый секрет может не отображаться — это нормально. Приватный ключ вводи только в этот запрос Cloudflare.
4. Опубликуй Worker:

   ```powershell
   npx wrangler deploy
   ```

   В конце появится адрес вида `https://quest-panel-push.ТВОЙ-АДРЕС.workers.dev`. Скопируй его.

## Часть 4. Подключи сайт к Worker

1. Открой `push-config.js` в корневой папке `planner`.
2. Замени `https://YOUR-WORKER.YOUR-SUBDOMAIN.workers.dev` на адрес Worker из предыдущего шага.
3. Замени `PASTE_VAPID_PUBLIC_KEY_HERE` на значение `Public Key`. Ключ должен остаться в кавычках.
4. Сохрани файл. В GitHub Desktop появятся изменения — создай commit и нажми **Push origin**.
5. Подожди, пока GitHub Pages опубликует обновление, затем открой [планер](https://svccdev.github.io/planner/) на телефоне и обнови страницу.

## Часть 5. Включи уведомления на Samsung S26+

1. Открой сайт в Chrome на телефоне и установи его на главный экран, если он ещё не установлен.
2. Открой планер, перейди в **Профиль → Уведомления** и нажми **Включить уведомления**.
3. Когда Android спросит разрешение — нажми **Разрешить**.
4. Нажми **Отправить тестовое уведомление**. Если оно пришло, настройка закончена.

Если уведомления не приходят, открой системные настройки Android → Приложения → Chrome (или установленный планер) → Уведомления и проверь, что они разрешены. Также проверь, что `push-config.js` содержит адрес Worker и публичный ключ без пробелов и лишних символов.

## Как работают напоминания

- Push приходит в начале каждого блока расписания по часовому поясу телефона. В 12:00 приходит приветствие «Хорошего и продуктивного дня! Ты сможешь».
- Если остались основные квесты, напоминание приходит за 30 минут до последнего блока сна по расписанию дня.
- Созвон приходит общим уведомлением за 10 минут до указанного времени. Нажатие открывает планер на нужной вкладке; список встреч удаляет созвон через 5 минут после начала.
- Для расписания и напоминаний Worker проверяется раз в минуту. Уведомления требуют интернета и разрешения Android.

## Если нужно выключить или обновить

- В планере открой **Профиль → Уведомления → Отключить**. Это удалит подписку и связанные с ней записи из базы Cloudflare.
- Для изменения кода Worker снова открой PowerShell в `cloudflare` и запусти `npx wrangler deploy`.
- Не удаляй базу D1, пока пользуешься уведомлениями.

Команды и названия настроек сверены с официальной документацией Cloudflare: [создание D1 и миграции](https://developers.cloudflare.com/d1/wrangler-commands/), [секреты Worker](https://developers.cloudflare.com/workers/configuration/secrets/), [Cron Triggers](https://developers.cloudflare.com/workers/configuration/cron-triggers/).
